Method

How to read and reproduce the evidence

Reference Oracle
PySceneDetect v0.7 is invoked through the pinned headless Python environment used by the repository's parity work.
Candidate
The Rust release CLI is measured end-to-end rather than timing an isolated Detector function.
Benchmark Corpus
Deterministically generated media covers all five supported Detector families. Optional real-video cases are local and the media itself is not committed.
Publication
Timing output is curated into committed JSON evidence. The September generated run is identified by its GitHub-hosted runner; the June full snapshot keeps its original local provenance. Pages only validates and publishes static files.

Interpretation

What these numbers do and do not establish

Each benchmark data set is evidence about one measured Candidate on one machine at one point in time. The September generated run is the current deterministic comparison; the June snapshot is historical evidence with additional real-video coverage. Neither proves cross-machine speed or correctness. Correctness remains owned by deterministic tests and required parity cases.

For supported behavior, use the Capabilities reference. For the actual browser product surface, use the Workbench.
