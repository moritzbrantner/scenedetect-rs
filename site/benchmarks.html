Method

Same-run ratios are useful; cross-machine absolutes are not comparable

Reference Oracle
PySceneDetect v0.7 runs through the pinned headless Python environment used by parity work.
Candidate
The Rust release CLI is measured end-to-end, including decode, Detector execution, and Scene List CSV output.
History
site/data/benchmark-history.json indexes committed immutable snapshots. A snapshot retains its original machine and Candidate provenance.
Interpretation
Relative results inside one snapshot compare commands on the same runner. Absolute timings from different snapshots must not be treated as a time series unless the environment is demonstrably equivalent.
