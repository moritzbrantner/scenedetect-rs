Method

How the published numbers are produced

Reference Oracle
PySceneDetect v0.7 is invoked through the pinned headless Python environment used by the repository's parity work.
Candidate
The Rust release CLI is measured end-to-end rather than timing an isolated Detector function.
Benchmark Corpus
Deterministically generated media covers all five supported Detector families. Optional real-video cases are local and the media itself is not committed.
Publication
The ignored local hyperfine report is converted into the committed site/data/benchmarks.json snapshot. Pages only validates and publishes that static data.

Interpretation

What these numbers do and do not establish

A Published Benchmark Snapshot is evidence about one measured Candidate on one machine at one point in time. It can show a useful performance direction, but it does not prove current main performance, cross-machine speed, or correctness. Correctness remains owned by the repository's deterministic tests and required parity cases.

For supported behavior, use the Capabilities reference. For the actual browser product surface, use the Workbench.
