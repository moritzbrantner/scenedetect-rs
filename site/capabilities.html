Capability reference

What scenedetect-rs can prove today

This page describes demonstrated public behavior, not an aspirational feature list. Detector parity is backed by the repository's required PySceneDetect v0.7 Parity Cases; native and browser capabilities are stated with their ownership and timing boundaries.

The authoritative detector matrix remains tests/parity/capability-matrix.md .

Native workflow

Detection data is the reusable product boundary

Detection Stats
scenedetect-rs detect … writes a sibling *.scenedetect.json artifact containing Detector provenance, per-frame scores, decisions, and metrics. Native render commands consume that artifact.
Derived output
Scene List, stats CSV, HTML, and boundary-review outputs can be derived from matching Detection Stats without repeating the original detection pass.
Exact Media Time
render timeline produces a versioned Scene Timeline with integer-tick, rational-time-base endpoints. It deliberately re-reads the timing-aware Frame Source and does not rewrite Detection Stats.
Frame Source
The native CLI acquires frames through the FFmpeg subprocess adapter. Detector truth remains owned by the Rust core rather than the media adapter.

Browser workflow

Local analysis with an explicit browser boundary

Local media
The selected video stays on the device; the static site has no upload endpoint.
Decode and sampling
The browser owns video decode, presentation synchronization, canvas reads, and sampling. This surface does not claim native FFmpeg decode or VFR parity.
Rust Detector semantics
Sampled RGB frames are transferred to a worker and processed by the Rust Detector core compiled to WebAssembly.
Human review
Boundary review remains separate evidence from Detector output and can be exported with the workbench session artifacts.

Compatibility boundary

Compatibility is a seam, not the native data model

PySceneDetect-compatible commands remain available for parity and migration work. CSV is the default list-scenes format used by parity; JSON, NDJSON, and self-contained HTML Scene List output are also available. Flexible command ordering after a Detector command remains deliberately outside the initial compatibility scope.
