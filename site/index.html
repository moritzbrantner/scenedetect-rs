Rust scene detection CLI

scenedetect-rs

A Rust reimplementation and expansion of PySceneDetect, focused on CLI-compatible scene detection, FFmpeg frame acquisition, and parity against the PySceneDetect v0.7 Reference Oracle.

View source See benchmarks

CLI shape

PySceneDetect-compatible command direction

The first milestone targets detect-content, detect-adaptive, and detect-threshold, detect-hist, detect-hash, scene-list CSV output, and detector stats CSV output. 

scenedetect-rs -i input.mp4 --output out detect-content list-scenes
scenedetect-rs -i input.mp4 --stats stats.csv detect-content list-scenes --no-output-file
